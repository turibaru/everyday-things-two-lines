Two lines about an everyday thing, written for a ten-year-old: the first line
explains it with one surprising analogy, and the second line explains honestly
what the analogy maps and what it leaves out.

`main.ts` reads `entry.txt` at runtime and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, refusing entries over 400 code points.
